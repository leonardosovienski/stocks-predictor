# Pre-winner rank trajectories

`analysis/pre_winner_rank_trajectories.csv` materializa rank, percentil, score e seleção de -3 a +3 meses do início de cada episódio. O padrão é heterogêneo: winners aparecem tanto já rankeados quanto abaixo do corte, e a maioria dos misses amplos é demonstravelmente `RANK_TOO_LOW`. Não há base para um novo threshold escolhido retrospectivamente.
