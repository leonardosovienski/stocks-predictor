# Scripts históricos preservados na main

Este acervo completa os helpers autorais que ainda estavam somente no chat. ORIGENS.json também aponta as cópias já versionadas, comparando conteúdo com LF. Scripts antigos mantêm seus bytes, caminhos absolutos e comportamento histórico. Alguns escrevem bancos ou consomem evidência: não executar automaticamente.

Os helpers de exportação integral são registros da primeira migração, que incluía código. Para a entrega separada atual, usar tools/data_transfer.py e docs/continuation/MIGRACAO_MAIN.md. Bibliotecas instaladas e cópias de wheels não são código autoral deste repositório.
