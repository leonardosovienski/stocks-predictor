# Raiz local única do projeto Stocks

Pedido do usuário em 09/09/2026: todo o conteúdo local deste projeto deve ficar
em `C:\STOCKS`. Esta é a raiz canônica para novas execuções.

- Código e histórico Git: `C:\STOCKS\stocks-predictor`.
- Fontes e arquivos originais de migração: esta raiz e `FONTES_WEB_ORIGINAIS`.
- Pesquisa, downloads pontuais, logs, temporários e recibos: `C:\STOCKS\work`.
- Entregas e relatórios locais: `C:\STOCKS\outputs`.
- Prompt original: `C:\STOCKS\instructions\STOCKS_PREDICTOR_PROMPT_FINAL_20260909.md`.
- Mapa e conferência da centralização: `C:\STOCKS\LOCALIZACAO_PROJETO.json` e
  `C:\STOCKS\work\centralizacao-20260909`.

Definir explicitamente o diretório de trabalho dentro de `C:\STOCKS` em cada
comando. Não gravar conteúdo do projeto em Downloads, Documents/Codex ou outros
diretórios locais. Diretórios de saída devem resolver para dentro desta raiz.
Não criar links que desviem dados do projeto para fora dela.

Ler também as instruções do repositório antes de alterar código. Manter trabalho
individual, sem agentes auxiliares, conforme o mandato. Preservar fontes,
protocolos, lacres e recibos antigos: seus caminhos são proveniência histórica;
consultar o mapa atual sem modificar esses bytes para corrigir caminhos.

Python e ferramentas já instalados pelo Codex são recursos do ambiente. Não
mover, copiar ou alterar essas instalações, nem históricos/caches internos do
aplicativo. O repositório remoto GitHub continua sendo o remoto autorizado.
Esta centralização refere-se aos arquivos locais autorais e dados do projeto.
