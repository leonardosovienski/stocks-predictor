Cvxportfolio modela limites de giro, participação e exposição separadamente. Seu modelo de custos admite termo linear e impacto não linear; só o custo linear foi usado no protótipo. O código fixado possui texto de licença GPLv3. Usamos conceitos matemáticos com implementação própria, sem dependência ou cópia; vendor/dependência futura exige revisão de compatibilidade. A documentação consultada [constraints](https://www.cvxportfolio.com/en/stable/constraints.html) era1.5.0, e o tag1.5.0 foi resolvido ao commit82bbceb. O teste remoto solicitado em`tests/test_constraints.py` retornou404; não alegamos tê-lo examinado ou executado.

Escolhas de reutilização: Qlib MIT, LEAN/Zipline/Alphalens Apache2, scikit BSD3 (classificação herdada, headers do código consultados). Todos são REIMPLEMENTATION/REFERENCE_IMPLEMENTATION conceitual nesta fase. Não foram instalados. Fontes externas arquivadas mantêm seus notices/licenças; nenhum código externo entrou no módulo. Para futura cópia MIT conservar notice/licença; Apache manter notices/licença e indicar modificações; BSD conservar condições. Licença do paper/dataset não concede automaticamente licença de software ou redistribuição de dados.

Aprimoramentos de dados: [ALFRED](https://fred.stlouisfed.org/docs/api/fred/realtime_period.html) explicita `realtime_start`/`realtime_end`, incluindo revisões; o padrão é hoje. Isso resolve uma capacidade que um simples wrapper SGS não fornece: consultar uma vintage. Não demonstra cobertura de séries brasileiras ou publicação intradiária. R62 é STUDIED, não integrado; API autenticada não foi usada.

O [NEFIN](https://nefin.com.br/) oferece fatores e datasets brasileiros úteis a K10/K09. Na página observada, fatores/short interest alcançavam2026, mas várias séries tinham últimas observações em2020–2023 e o índice de iliquidez não tinha arquivo publicado. Usar fonte seletivamente, verificando calendário/unidade/vintage; acesso público não certifica redistribuição nem alpha. Prioridade: fatores para diagnóstico. Opções/volatilidade implícita, aluguel e curva de juros ficam LATER se a cobertura servir ao experimento.

A comparação externa é funcional por trecho inspecionado. Nenhum projeto inteiro foi declarado financeiramente superior. Qlib/scikit têm contratos de transformadores maduros; Alphalens/Qlib têm relatórios cross-sectional; Cvxportfolio tem restrições que o seletor atual não oferece; LEAN/Zipline têm referências amplas de execução/ajuste. Onde o Stocks já tem hashes, preservação, seleção histórica, pesos iguais e custo ponderado, a decisão é KEEP. Não substituir módulos corretos para adotar uma marca.
